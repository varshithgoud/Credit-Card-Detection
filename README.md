# Credit-Card-Detection
Credit Card Fraud Detection
Show Image

Overview
Machine learning solution for detecting fraudulent credit card transactions using Random Forest classifier and SMOTE.

Key Features
Handles highly imbalanced data (0.17% fraud cases)
Achieves 97% ROC-AUC score
Employs data balancing with SMOTE
Compares Logistic Regression and Random Forest models
Results
Model	ROC-AUC
Logistic Regression	0.96
Random Forest	0.97
Quick Start
bash
# Clone repository
git clone https://github.com/yourusername/credit-card-fraud-detection.git

# Install dependencies
pip install -r requirements.txt

# Run the main script
python credit_card_fraud_detection.py
